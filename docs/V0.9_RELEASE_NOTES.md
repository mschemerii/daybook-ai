# Daybook AI v0.9 — Release Notes

**Status:** prepared for release review; not yet published.

## Highlights

- Native PySide6 desktop application is the authoritative interface.
- Deterministic tasks, epics/subtasks, dependencies, blocking relationships,
  dated time entries, completion enforcement, reporting, and exports.
- Completion snapshots and blocker history preserve later reporting context.
- Epic time is cumulative from descendant task entries and is not double-counted.
- Local Qwen inference through llama.cpp for grounded explanations and optional
  decomposition proposals.
- Human review and explicit approval before AI-originated task persistence.
- Deterministic fallback when local AI is unavailable.
- PDF report export and UTF-8 CSV ZIP export.
- Local SQLite persistence with versioned migrations and pre-migration backups.

## Phase 10 cleanup

Streamlit, the browser controller/runtime, Playwright acceptance tests, and
browser screenshot tooling are no longer supported. Shared llama.cpp startup,
verification, ownership, and shutdown logic is retained in a UI-neutral runtime
module.

The old standalone `seed_data.py` entry point is removed. Demo content uses
`src.repositories.demo_seed.seed_demo_data` when composition enables demo
seeding.

## Known limitations

- Single-user local application.
- No encryption-at-rest layer.
- Small local models may be weak or malformed; deterministic fallback remains
  authoritative.
- Cross-platform executable packaging and GitHub Releases are Phase 12 work.
- Phase 11 refinements are not part of this release preparation.
